## Kiến thức thực hành

- Sử dụng bộ chọn CSS và định dạng chữ, màu sắc, nền, đường viền, khoảng cách.
- Xử lý nội dung tràn và tạo hiệu ứng bóng chữ, bóng khung.
- Tổ chức bố cục bằng `inline-block`, CSS Grid và các thuộc tính định vị.
- Sử dụng `z-index`, phần tử giả và trạng thái `:hover`.
- Tích hợp biểu tượng Font Awesome thông qua CDN.

## Cách mở bài trên máy

1. Mở thư mục `Tuan3/VeNha` trong bản repository trên máy.
2. Mở `index.html` bằng trình duyệt.
3. Chọn bài cần xem từ trang tổng hợp. Trong Bài 3, chọn từng Exercise từ danh sách Lab CSS.
4. Mở các tệp `.docx` bằng Microsoft Word để xem báo cáo và tài liệu kèm theo.

Cần kết nối Internet để tải các ảnh và thư viện được liên kết từ nguồn bên ngoài.
