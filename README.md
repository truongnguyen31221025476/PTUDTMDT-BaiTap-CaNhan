## Hướng dẫn xem bài

- **Bài theo tuần.** Mở trang GitHub Pages ở hàng tương ứng. Trong thư mục mã nguồn, `TrenLop/` chứa bài thực hành tại lớp và `VeNha/` chứa bài tập về nhà ở các tuần có giao bài.
- **JavaScript Labs.** Chọn Lab 08, 09 hoặc 10, sau đó chọn Exercise. Với bài xuất kết quả qua `console.log`, mở **F12 → Console**. Khi chạy bài GET trên máy, mở trang qua máy chủ cục bộ, chẳng hạn Live Server trong VS Code.
- **Advanced FrontEnd.** Từ trang giới thiệu, chọn TechStore để xem cửa hàng hoặc Flappy Noël để chơi. Với bài jQuery, mở hướng dẫn, đăng nhập LMS UEH bằng tài khoản có quyền vào học phần rồi chạy đoạn mã trong Console của trang học phần. Có thể đối chiếu kết quả với ảnh trong báo cáo nhóm 2. Các màn chơi nhóm 3 được trình bày trong báo cáo riêng.
